# Security

Wooju runs a local server on your Mac (127.0.0.1 only, and it answers only
requests addressed to this Mac). Your notes stay in a folder you choose; API
keys and the Telegram bot token are kept in the macOS keychain, never in files.

If you find a way to read or change someone's notes, reach the local server
from a web page, or extract stored keys, please report it privately through
GitHub's "Report a vulnerability" (Security tab) rather than in a public issue.
