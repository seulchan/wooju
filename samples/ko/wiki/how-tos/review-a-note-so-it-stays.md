# 노트가 남도록 복습하기

## 언제 쓰나

나중에 기억으로 꺼내 쓰고 싶은 노트에. 대화에서 필요할 개념, 방법, 자꾸 다시 찾아보게 되는 숫자 같은 것.

## 순서

1. 노트를 열기 전에, 기억나는 것을 말하거나 적어 본다. 1분이면 충분하다.
2. 노트를 열고 비교한다. 놓친 부분을 표시한다.
3. 맨 아래에 내 말로 한 줄을 더한다. 나에게 어떤 뜻인지, 어디에 쓸지.
4. 다음 복습은 지난번보다 더 멀리 잡는다. 잘 떠오르지 않았다면 반대로 가깝게 잡는다.

## 주의할 점

- 다시 읽기는 공부하는 느낌이 들지만 그렇지 않다. 1번의 떠올리기가 실제 일을 한다. ([다시 읽기는 도움이 되긴 하나?](../questions/does-rereading-help-at-all.md) 참고)
- 모든 노트를 복습하지 않는다. 잊으면 아쉬울 노트만 고른다.
- 너무 촘촘한 일정은 건너뛰게 된다. [간격 효과](../concepts/spacing-effect.md)가 말하듯, 짧게 여러 번보다 길게 몇 번이 낫다.
