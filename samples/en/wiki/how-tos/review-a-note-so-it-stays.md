# Review a note so it stays

## When to use it

For a note you want to be able to use from memory later: a concept you will need in conversation, a method, a number you keep looking up.

## Steps

1. Before opening the note, say or write what you remember of it. One minute is enough.
2. Open the note and compare. Mark what you missed.
3. Add one line in your own words at the bottom: what it means for you, or where you would use it.
4. Set the next review further away than the last one. If recall was poor, bring it closer instead.

## Watch out for

- Rereading feels like learning but is not; the recall attempt in step 1 does the work (see [Does rereading help at all?](../questions/does-rereading-help-at-all.md)).
- Do not review everything. Pick the notes you would be sorry to forget.
- A schedule that is too dense gets skipped. Fewer, longer gaps are better than many short ones, as the [spacing effect](../concepts/spacing-effect.md) suggests.
